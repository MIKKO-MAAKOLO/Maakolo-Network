# 🌐 Maakolo Network

An experimental VPN and proxy project built by a team of friends. We started this to dive deep into network protocols, traffic routing, and backend development. 

Right now the project is on hold, but we plan to pick it back up and evolve it in the future.

### 💡 Why We Built It
Instead of just reading theory, we wanted to build a working infrastructure from scratch to understand how modern proxy frameworks operate under the hood. It’s a non-commercial pet project created out of pure interest to level up our engineering and security skills.

### 🛠 Tech Stack
- **Backend API:** Python 3, Flask, PostgreSQL
- **Core Engine:** Xray-core / Sing-box
- **Client App:** Flutter (Dart)
- **Protocols:** VLESS, Reality

### 👨‍💻 My Focus in the Team
- Developing the backend API using Python (Flask).
- Setting up and managing PostgreSQL for user data.
- Exploring server-side orchestration and networking.
